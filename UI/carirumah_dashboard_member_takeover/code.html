Panduan Over-Kredit Sah

Patuhi 3 langkah aman hukum perbankan Indonesia agar Anda terbebas dari tuntutan kredit macet.

  1. 1

    Siapkan SP3K & Rekening Koran

    Minta rincian sisa pokok angsuran terkini dari bank KPR Anda (BTN/BSI/Mandiri).

  2. 2

    Verifikasi Identitas Pembeli

    Pastikan calon pembeli disaring melalui tim CariRumah untuk verifikasi BI Checking / SLIK OJK.

  3. 3

    Tanda Tangan Akta PPAT

    Penerbitan akta pengikatan jual beli (PPJB) dan kuasa melunasi di depan Notaris Rekanan OJK Banten.
